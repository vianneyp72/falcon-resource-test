# falcon-resource-test

Measure how much CPU and memory CrowdStrike Falcon uses in your Kubernetes cluster, then remove the tool.

Install it, watch Falcon's live usage, run a timed assessment (15m, 30m, or 1h) for averages, peaks, and health checks, and export the report. It's read-only, small, and leaves nothing behind once you uninstall it.

> **Status:** Under construction. The design is in [`docs/design/design.md`](docs/design/design.md) and the implementation plan in [`docs/plan/`](docs/plan/00-index.md).

The how-to guide for Sales Engineers lives in the [falcon-cloud-security-labs](https://github.com/vianneyp72/falcon-cloud-security-labs) site.
